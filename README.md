# CalcX Developer Website – GitHub Pages

This is a static GitHub Pages website containing:

- Developer home page
- CalcX app page
- Privacy Policy
- Contact / support page

## Before publishing

Replace these placeholders in all HTML files:

- `YOUR DEVELOPER NAME`
- `YOUR-EMAIL@example.com`

Also update the Google Play link in `index.html` to your actual CalcX Play Store URL.

## GitHub Pages setup

1. Create a repository named `<your-github-username>.github.io` for a developer/user site.
2. Upload all files from this folder to the repository root.
3. Open repository **Settings → Pages**.
4. Under the build/deployment source, select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Your website will be available at:
   `https://<your-github-username>.github.io/`

Privacy Policy:
`https://<your-github-username>.github.io/privacy-policy.html`

Contact:
`https://<your-github-username>.github.io/contact.html`

GitHub Pages may take a few minutes to publish changes.

## Important

Review the Privacy Policy against the exact SDKs/services used by the released CalcX app and make sure it matches the Google Play Data Safety form.
