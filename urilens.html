URI Lens

Deep Link & URI Inspector designed to make URI analysis, URL inspection and Android deep-link testing quick, clear and practical.

PROJECT OVERVIEW

Inspect, understand and test links.

URI Lens is a focused Android utility for developers and technical users. It provides a simple way to inspect URI components, analyze query parameters, encode or decode URLs, and test whether installed Android applications can handle a deep link.

URI Inspector Analyze schemes, hosts, ports, paths, queries and fragments.
Deep Link Tester Test Android deep-link resolution using the device's actual Intent system.
Query Parameters Inspect individual query parameters and their values with easy copy actions.
Encode & Decode Encode or decode URI text using standard URL encoding and decoding.
Link History Keep recently inspected and tested URIs available locally on the device.
Share & Copy Quickly copy URI information or share links using Android's standard tools.
Platform Android
